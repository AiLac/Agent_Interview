# 第 2 小时 · 把嵌套字典读成数据流

**本节产物**是地点工具内部的纯函数。输入是一组地点、一个词和数量上限；输出是按输入顺序排列的地点名称。训练重点是读懂 Agent 源码中常见的列表套字典，以及一行里同时出现的过滤与取值。

## 0–12 分钟 · 给每个中间值标明形状

```python
from agent_lab.core import PLACES

for index, row in enumerate(PLACES, start=1):
    name, tags = row["name"], row.get("tags", [])
    print(index, name, tags)
```

`enumerate` 每次给出一对值，循环头把它们解包给两个变量。字典直接迭代会得到键，需要成对取键和值时用 `.items()`。`row["name"]` 假定字段必须存在，缺失会抛 `KeyError`；`get("tags", [])` 允许可选标签缺失。若字段显式写成 `None`，`get` 会原样返回它。课程样本约定标签缺失或是字符串列表；接入新来源时要先检查这个约定。

| 你要表达的数据 | Python 写法 | 在本例中的作用 |
| --- | --- | --- |
| 有顺序、可追加的一组记录 | `list`，如 `[]` | 保留输入顺序，收集名称 |
| 固定位置的一对值 | `tuple`，如 `(index, name)` | 迭代时解包 |
| 从字段名定位值 | `dict`，如 `{"name": "北岸图书馆"}` | 表达 JSON 对象或工具表 |
| 判重、集合差 | `set`，空集合写作 `set()` | 判断参数是否含未支持的键 |

## 12–27 分钟 · 展开一行推导式

```python
from agent_lab.core import PLACES

word = "安静"
names = [row["name"] for row in PLACES if word in row.get("tags", [])]
print(names[:1])
```

阅读顺序是 `for row in PLACES` 找记录，`if ...` 决定取舍，最后用左侧的 `row["name"]` 生成结果。若习惯 Java Stream，可以写下对应的三个动作：遍历、filter、map。这个列表推导式会立刻构造列表。切片 `[:1]` 取索引 0 到 1 之前的元素，返回新列表；切空列表仍是空列表。把 `[:1]` 换成 `[0]` 并改查「海滩」，观察 `IndexError`。

把上面的推导式还原成显式的 `for`、`if` 和 `append`，再把名称匹配加进去。字符串中的 `in` 检查子串，列表中的 `in` 检查元素相等，所以「安」可以命中名称里的「安」，却无法命中完整标签「安静」。这是两处看起来相同、业务含义不同的表达式。

在 [practice.py](../practice.py) 实现 `find_places(rows, query, *, limit=2)`：

## 50–60 分钟 · 解释源码中的两个陷阱

试写 `def collect(name, out=[]): ...`，函数体中追加名字并返回列表，连续调用两次。默认值在函数定义时求值，第二次会看到上一次留下的数据。一个 Agent 的消息如果混入上一次会话，先检查默认列表和实例属性的创建时机。修正方法是把缺省值设成 `None`，在函数内部 `if out is None: out = []`；调用者显式传入的空列表也应被保留。

如果需要跨来源去重并保序，对字符串列表可以用 `list(dict.fromkeys(names))`。先用 `["A", "B", "A"]` 推演一次。这里利用字典保留插入顺序；直接 `list(set(names))` 无法保证原来的顺序。进阶课会用到这一点。
